# 쿼리도 🧱

컴퓨터와 하거나 방 코드로 친구와 실시간 대결하는 쿼리도. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. `public/`(`index.html` + `logic.js` + `game.js`)과 온라인 대전용 `server.js`(`ws`)로 이루어져 있습니다.

- **규칙**: 9×9 판, 말은 한 칸씩 움직이고 상대 쪽 끝줄에 먼저 닿으면 이긴다. 한 턴에 **말을 한 칸 움직이거나 벽(두 칸 길이)을 하나** 놓는다. 벽은 한 사람당 10개
- **뛰어넘기**: 상대 말이 바로 앞이면 뛰어넘고, 그 뒤가 벽·판 끝이면 대각선으로 비켜 간다
- **벽 규칙**: 겹치거나 십자로 엇갈리게 놓을 수 없고, **상대(또는 나)의 길을 완전히 막는 벽은 놓을 수 없다**(너비 우선 탐색으로 두 사람 모두 끝줄까지 길이 남는지 검사)
- 화면: 말 이동은 갈 수 있는 칸의 점을 누르고, 벽은 **벽 놓기**를 눌러 판을 누르거나 끌면 미리보기(주황 = 가능, 빨강 = 불가)가 뜨고 **✔ 놓기**로 확정. 남은 벽 수와 **목표까지 남은 칸 수**를 이름표에 표시. 상대가 방금 둔 수는 점선 출발 칸과 반짝이는 고리(말) 또는 주황 빛(벽)으로 보인다. 뒤 플레이어는 판이 뒤집혀 내 말이 늘 아래
- 컴퓨터: 쉬움은 최단 경로를 따라 걷다가 가끔 벽을 놓고 12% 는 아무 수나 둔다. 어려움은 0.6초 안에서 깊이를 늘려(최대 2수 — 사람이 이길 만하게 예전 4수에서 낮춤) 미니맥스 탐색(후보: 말 이동 + 상대의 최단 경로를 막는 벽). 어려움이 쉬움을 이긴다(시험으로 확인)
- 컴퓨터를 이긴 횟수는 `quoridorWins` (로비 표시용)
- **온라인 대전**: 빠른 대전 · 4글자 방 코드(초대 링크 `?room=코드`) · 재접속(30초) · 한 수 제한 시간 · 기권 · 한 판 더(선후 교대). 서버가 같은 규칙(`public/logic.js`)으로 모든 수를 검사한다(차례가 아니거나 규칙에 어긋난 수는 무시)

규칙과 컴퓨터는 `public/logic.js`(화면 없이 Node 로 시험), 화면·입력·소리·온라인은 `public/game.js`, 방·매칭은 `server.js`. 시험은 `npm test`(= `node --test`): `test/logic.test.js`(벽 막힘·뛰어넘기·겹침/교차·길 막기 금지·컴퓨터), `test/server.test.js`(매칭·입력 검사·끝줄 도달·기권·한 판 더·시간 초과).
